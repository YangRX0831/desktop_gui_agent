# 桌面 GUI 智能体原型系统

本项目基于多模态大模型开发一个能够感知桌面内容、理解自然语言指令并执行鼠标键盘操作的桌面 GUI 智能体原型。

系统采用“感知-思考-执行-反馈”的工作流程：获取当前屏幕内容，由多模态模型理解用户任务并生成下一步操作，再通过桌面控制模块执行动作，循环处理直至任务完成或达到最大执行步数。

## 核心能力

- 截取桌面屏幕并识别其中的文字和 UI 元素
- 根据自然语言指令理解任务并规划操作步骤
- 执行鼠标移动、点击、拖拽和键盘输入等操作
- 解析模型生成的动作指令并管理任务执行状态
- 提供命令行交互、错误处理、自动重试和日志记录
- 支持基础桌面任务的端到端自动执行
